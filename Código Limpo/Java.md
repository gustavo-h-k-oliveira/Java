# História e Evolução do Java

## As Origens do Java

Java surgiu no início da década de 1990 na empresa *Sun Microsystems*, liderado por *James Gosling*.

## A Linhhagem do Java

Java herdou características de várias linguagens:

* C → sintaxe básica
* C++ → orientação a objetos
* Smalltalk → modelo mais puro de objetos

Mas Java removeu elementos considerados perigosos ou complexos, como:

* Ponteiros explícitos
* Sobrecarga de operadores
* Herança múltipla de classes

O objetivo era tornar a linguagem mais segura e robusta.

## Os "Buzzwords" do Java

* *Simple* → sintaxe familiar, mas sem recursos inseguros
* *Object-Oriented* → tudo gira em torno de classes e objetos
* *Robust* → verificação de erros em tempo de compilação e execução
* *Secure* → execução controlada, especialmente importante para a Web
* *Architecture-neutral*
* *Portable*
* *High-performance*
* *Multithreaded*
* *Distributed*
* *Dynamic*

Uma frase que resume bem essas ideias:

"*Write once, run anywhere.*"

## Bytecode e JVM

O processo é:

1. Código Java → compilado pelo `javac`
2. Gera bytecode (.class)
3. A JVM executa o bytecode

Esse modelo é fundamental para entender:

* Portabilidade
* Segurança
* Independência de plataforma
